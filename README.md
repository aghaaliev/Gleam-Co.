# Gleam Co - Silver Accessories E-commerce Website

A modern, elegant jewelry e-commerce website for Gleam Co, featuring premium silver accessories.

## Features

- **Modern Design**: Minimalist and luxury aesthetic with silver (#C0C0C0, #E8E8E8) and dark blue (#0A1628, #1E3A5F) color scheme
- **Homepage**: Eye-catching hero section with call-to-action
- **Product Gallery**: Grid layout showcasing all available products
- **Product Details**: Individual pages for each product with detailed information
- **Shopping Cart**: Full shopping cart functionality with localStorage persistence
- **Contact Form**: Professional contact form for customer inquiries

## Pages

- `index.html` - Homepage with hero section and featured products
- `products.html` - Complete product catalog
- `product-detail.html` - Individual product pages
- `cart.html` - Shopping cart with checkout functionality
- `contact.html` - Contact form

## Technology Stack

- HTML5
- CSS3 (Custom styling with CSS variables)
- Vanilla JavaScript (No frameworks)
- LocalStorage for cart persistence

## Color Palette

- **Primary Dark**: #0A1628
- **Primary Blue**: #1E3A5F
- **Accent Silver**: #C0C0C0
- **Light Silver**: #E8E8E8
- **White**: #FFFFFF

The website features 12 premium silver accessories including:

## Usage

Simply open `index.html` in a web browser to view the website. All functionality works without requiring a server.

## Shopping Cart

- Add products to cart from any product page
- View cart count in navigation
- Remove items from cart
- See subtotal, tax, and total
- Checkout functionality (demo mode)
